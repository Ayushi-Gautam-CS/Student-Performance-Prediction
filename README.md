# Student Performance Prediction

## 📌 Project Overview
This project focuses on analyzing student performance data and understanding the factors that affect students' academic results.

## 📊 Dataset
The project uses student performance datasets containing information related to students' academic performance, personal background, and other factors.

Files included in this repository:

- `student-mat.csv` – Student performance data for Mathematics.
- `student-por.csv` – Student performance data for Portuguese language.
- `student-merge.R` – R script for merging and analyzing the datasets.
- `student.txt` – Information and details about the dataset.

## 🎯 Objective
The main objective of this project is to analyze student data and explore the factors that may influence academic performance.

## 🛠️ Technologies Used
- R Programming
- Data Analysis
- CSV Datasets
